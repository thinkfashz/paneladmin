# Contributing to Studio Admin

Thank you for your interest in contributing! Here’s how to get started.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/next-shadcn-admin-dashboard.git`
3. Install dependencies: `npm install`
4. Start dev server: `npm run dev`

## Reporting Issues

- Search existing issues before creating a new one
- Include steps to reproduce and browser/OS info

## Pull Requests

- Fork → branch → commit → pull request
- One feature/fix per PR
- Test your changes before submitting
- Add a clear description of what you changed and why

## Code Style

- Run `npm run check` before committing (uses Biome)
- Follow existing patterns in the codebase
- Use TypeScript types throughout

## Questions

Open a GitHub issue or start a discussion.
